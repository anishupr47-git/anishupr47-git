### Core Systems & Engineering Proof Points

* **National AI Hackathon 2026 Champion (1st Place):** Architected the low-latency dual-stack backend for `DRISTI_OS`, coordinating asynchronous streaming speech-to-text, tool execution, and reasoning models.
* **`tiered-semantic-cache`:** Author and maintainer of an offline, two-tiered semantic caching engine. Implemented a custom AsyncIO TCP daemon on the Redis RESP wire protocol, O(1) LRU eviction, and zero-copy `mmap` disk persistence, cutting redundant query latency from ~3s to sub-milliseconds.
* **`towergb`:** Author and maintainer of a Scikit-Learn compatible gradient-boosted ensemble framework featuring automated missing data preprocessing and Platt/temperature probability calibration, validated across a 69-test automated CI/CD pipeline.
* **Systems & Data Infrastructure:** Engineered production microservices across Python (FastAPI, Django), Docker, Redis, and PostgreSQL; refactored database indexing and query layers to slash API latency by 30% to 35%.
